# 华为 × CCSA：网络运营管理知识图谱（含本体建模）行业标准

- 抓取日期：2026-09-20
- 核实状态：confirmed（全国标准信息公共服务平台 / 国家数字标准馆目录页；正文未公开）
- 归口：中国通信标准化协会（CCSA），主管部门工信部

## 用户点名「华为 CCSA 本体规范」的对应关系

公开目录 **没有** 名为「华为本体规范」或独立「通信网络 OWL 本体」的单一 CCSA 标准。与「本体」直接对应、且华为作为主要起草单位的，是 2026-06-01 发布的 **YD/T「网络运营管理知识图谱技术要求」系列** 中的知识建模分册（明确本体模型 / RDF / OWL）。

## 公开范围摘要（目录 + 标准解读文，正文未读）

YD/T 7007 适用范围：确立网络运营管理知识图谱知识建模一般准则，明确知识模型组成及表示方法，规定知识建模方法；适用于构建和维护。

二手解读（antpedia，[中]，不得当条款引用）：

- 两层模型：**本体模型**（实体类/属性/关系）与 **实例化模型**
- 知识表示：RDF 三元组，可扩展四元组/五元组（图名、时间）
- 七类运营数据建模：配置、性能、告警、故障、规则、意图、运营
- 推荐形式化语言：OWL / XML / JSON

YD/T 7011：总体框架、角色职责、交互流程、系统能力、交互接口。
YD/T 7023：知识单元融合、图谱集成、图谱扩展及融合任务。起草单位含华为、中兴、亚信、北邮、电信、联通、浪潮。
YD/T 7024：构建原则与过程（建模、数据获取、抽取、存储、融合、推理、质量评估）。
YD/T 7129：5G 无线故障管理知识模型与典型用例；明确不涉及设备网管及北向接口标准化。

## 与华为 ADN / TMF 同源性

- **已核实**：华为是上述行标的主要起草单位之一，不是唯一起草方。运营商（移动/电信/联通）与北邮居目录首位。
- **推断 [低]**：内容与 ITU-T M.3351（知识建模含 ontology modelling + RDF/OWL）及华为 ADN 白皮书「知识图谱沉淀专家经验」方向一致，但 **未见 CCSA 文本声明「等同采用 TMF GB1093/TIO」**。
- **不得写成**：存在一份由华为单独发布的「CCSA 本体规范」。
