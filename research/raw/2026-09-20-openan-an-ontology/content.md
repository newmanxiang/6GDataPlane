# OpenAN「AN Ontology」工作流归档

## LFN 公告（2026-06-25，MWC Shanghai）

Source: https://lfnetworking.org/lf-networking-brings-a2a-t-to-live-network-through-openan-for-agent-driven-autonomous-networks/

> OpenAN is a set of open source tools to implement Autonomous Networks (AN), which is defined in TM Forum’s AN Project, contributed by China Mobile and Huawei, and first unveiled at MWC Barcelona in March 2026.

> The OpenAN project encompasses three categories of open source components: the A2A-T common component, Agent Framework, and AN ontology. Phase 1 of the project prioritizes the development and promotion of open source components for A2A-T

支持/创始相关方（LFN 文）：China Mobile、Huawei，supported by AIS、AsiaInfo、Infosys、Orange、Personal **and ZTE**。

> As the chair of the OpenAN project, China Mobile, together with founding members such as Huawei, ZTE, and AsiaInfo

许可证：Apache 2.0。场景化 solution packages 计划 2026 下半年，商用验证目标 2027。

Phase 1 已公布的组件：A2A-T SDK、Registry Center、Orchestration Center。**未列出 ontology 仓库。**

## Telecom Review Europe（2026-06-25）

> The OpenAN project has planned three foundational projects: “Agent to agent for Telecom Public Components, Agent Framework, and AN Ontology,” and advanced the pilot innovation and commercial deployment of agent to agent for telecom public components in live networks.

即：三个奠基项目中，当前推进的是 A2A-T 公共组件；AN Ontology 仍是规划项。

## openan.dev（2026-09 访问）

时间线：

- 2026.03 MWC Barcelona：Kickoff（China Mobile + Huawei）
