# 信息框架（Information Framework，SID）

**一句话定义**：TM Forum 为 CSP 提供的企业级信息/数据参考模型与共用词汇，按域组织业务实体（ABE/BE）；现行发布格式为 UML/XMI 与 Excel（GB922 / MODA），官方尚无 OWL。

**来源**：[Information Framework (SID)](https://www.tmforum.org/open-digital-architecture/information-framework-sid/)

**相关概念**：
- [tm-forum](tm-forum.md)
- [tmf-an-ontology-project](../topics/tmf-an-ontology-project.md)

**易混淆点**：
- 与 TIO：SID 是信息框架，TIO 是意图本体。Catalyst「SID Ontology」指把 SID 转成 OWL KG，不是 TMF 官方发布形态。
- 与 Open API：Open API 的 schema 实现 SID 的一部分实体，但不能替代完整 SID。
