# 自智网络本体（Autonomous Network Ontology）

**一句话定义**：用 OWL/RDF 表达自智网络领域知识（意图词汇、SID 信息对象、故障/资源/工单等域模型），供 AN Agent 做语义一致的理解、推理与协同；OpenAN 将其列为与 A2A-T、Agent Framework 并列的奠基项目，但 2026-09 尚无官方仓。

**来源**：[LFN OpenAN](https://lfnetworking.org/lf-networking-brings-a2a-t-to-live-network-through-openan-for-agent-driven-autonomous-networks/)；[AsiaInfo AN-Ontology](https://github.com/asiainfo/AN-Ontology)

- [tmf-an-ontology-project](../topics/tmf-an-ontology-project.md)

**易混淆点**：
- 「AN Ontology」常被用来同时指 TIO、SID OWL 和厂商场景本体。深调卡将其拆成三层，见 topic。
