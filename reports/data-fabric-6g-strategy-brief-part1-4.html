数据编织如何成为 6G 数据面的「成品化」底座

综合最新 RAN 中心深度调研与初版通用报告，按战略模版输出前四部分：需求与目标、行业环境与竞争、产业趋势预判，以及「3 年看透、5 年看清」。判断均标注信心；标准未定结论处明确边界。

研究截点：2026-08 范围：模版前四部分 骨干：deep-research + initial-20260804 补充：3GPP Rel-21 / 厂商公开主张
01 · Needs & Goals

需求和目标

本简报要回答的不是「要不要跟风提 Data Fabric」，而是：6G 把网络变成数据生产者之后，数据管理层缺位如何补齐，以及数据编织以何种方式、在什么时间窗嵌入主航道。

需求（简述）

网络成为数据生产者，但「成品化」无人供给

6G 场景下，通感（ISAC）、AI 原生、数字孪生使网络同时产生感知、训练/推理与全网状态数据。业界围绕「数据面 / 数据框架」讨论运输与编排，但目录、语义、血缘、质量与用途治理仍系统性缺位。

运输不等于价值。运营商不会为「第二条管道」付钱；会付钱的是管道尽头可直接使用的成品——AI 特征与语料、合规感知产品、支撑孪生保真度的统一语义遥测。

编织要解决的四个动词

数据编织（Data Fabric）以主动元数据、语义、策略与多模式集成为控制面，使数据被找到、理解、信任、合规使用，并交付为可组合数据产品——不强制物理集中。

对 RAN 而言，价值不在把更多原始数据送往核心网，而在近源把高频短时效数据变成特征、事件与数据产品，服务闭环与模型生命周期。

一句话需求：把 6G「能产生的数据」变成「可行动的证据供应链」——在分布、实时与多主体约束下，降低获取摩擦，而不是堆存储与管道。

目标（简述）

研判基线：「需要数据编织」与「需要独立数据面」是两个独立命题。前者由数据管理层缺位论证；后者属传输/架构路线之争（SA2 等持续研究）。本简报建议路线无关（route-agnostic）：无论独立面、增强用户面或混合路线，统一的目录/语义/治理层都成立。
02 · Industry & Competition

行业环境或竞争现状

以需求为牵引：先看 6G 对数据管理层要什么，再看编织能供给什么、如何与 6G 结合及卡点，最后看标准与厂商如何争夺定义权与控制点。

2.1 6G 数据架构的范式转变与数据管理层需求

范式转变：从「连接管道」到「数据生产者」

IMT-2030 场景把 AI 与通信、通感一体等推到前台；3GPP 将 6G 研究放在 Rel-20，规范性工作在 Rel-21（Stage-3 计划 2028-12 冻结，ASN.1/OpenAPI 2029-03）。网络角色从数据管道扩展为数据生成者与消费者。

公开架构讨论中的「数据面 / 数据框架」多指支撑 AI、感知、孪生与自治的数据生产—处理—流通—消费能力集合——不是传统用户面（U-plane），也不是已冻结的单一标准网元。

对数据管理层的五项需求（D1–D5）

D1 统一框架：注册/发现、采集/分发、处理/存储、访问/暴露。
D2 AI 原生供数：跨域语义、血缘、特征级供给、联邦训练。
D3 感知服务化：分级分类、脱敏、授权与计费元数据。
D4 孪生供数：跨域遥测统一语义与变更传播。
D5 跨主体合规流动：策略即代码、用途控制、可审计出处。

时效层典型场景对数据管理层的要求边界
<10 ms（快环）设备内 / 确定性控制环外同步模型、策略与审计制品高 Fabric 不进关键路径
~10 ms–1 sNear-RT 特征、有界流短期状态、背压、对象映射；禁远端目录在线依赖有界近源处理
>1 s / 分钟+SMO/MDA、训练、治理、规划目录、血缘、契约、质量、策略——编织主战场企业能力可复用，缺电信本体
口径校准：①「亚毫秒」是控制系统指标，不是编织时延 KPI；②「ZB 级/天」类原始产生量估算（若成立）论证的是源头筛选与理解，不是全量存传投资。误读二者会导向错误平台方案。

2.2 数据编织能力全景、演进，如何与 6G 结合及关键技术挑战

能力全景（企业侧七层，可映射电信）

L1 分布式权威源 → L2 运行时节点 → L3 集成编排查询 → L4 主动元数据控制面 → L5 数据产品与自助 → L6 消费与行动；横切身份/质量/安全/驻留/审计/可观察。

经线是治理骨架，纬线是多模式交付，织机是主动元数据闭环。≠湖仓、≠被动目录、≠厂商产品名。

演进脉络

联邦数据库 → 信息编织/虚拟化 → 湖与混合云同名早期用法 → 2019 后主动元数据成为定义中心 → 2023 后进入 AI 上下文、数据产品与 Data Space。

成熟度事实：无单一 ISO/ITU/3GPP「Data Fabric」产品标准；品类可采购，组织可运营证据普遍落后于厂商叙事。

与 6G / RAN 的结合架构（综合初版与最新报告）

说明：接口层可映射 O1/E2/A1/R1 等，但接口本身不提供统一语义、血缘与 QoD；「RAN Data Fabric」为研究性抽象。

结合原则

能传事件不传连续流；能传特征不传原始；能下沉模型就不搬数据。跨域产品必须带责任人、Schema、QoD、用途、版本与保留期。

关键技术挑战

流式主动元数据；电信协议原生连接器；多模态/RAN 语义与三本体映射；边缘原生执行；线速治理与数据合约；Agent 供数的权限与审计。

失败模式

中央平台化；自动映射放大错误口径；策略级联；有目录无责任人；把中央编织塞进快环；把厂商 ROI 宣传当承诺。

2.3 标准与厂商竞争格局

标准域对「编织 / 数据框架」的贡献不负责 / 易误读
3GPP RAN测量、架构接口、无线程序——生产侧事实来源不定企业湖或完整 Data Fabric
3GPP SA5PM/CM/Fault/Trace、MDA、AI/ML 管理、NDT——管理数据主锚点不定毫秒调度；管理能力≠孪生保真度保证
O-RANNon-RT / Near-RT RIC；O1/O2/A1/E2/R1 分层智能无「RAN Data Fabric」组件；R1 不是 Core/AF 直暴露口
SA2 WT#5
6G data framework		系统级数据框架候选问题（发现/采集/处理/存储/暴露等）；Rel-20 研究中不预判统一网元；不是 RAN 内部架构中心，也不可简单说「只管核心网」
ETSI ZSM / MEC / TMF / CAMARA自动化集成、边缘、意图与网络 API 生态积木Integration Fabric ≠ 完整 Data Fabric；不宜进亚秒无线控制路径
IDS / Gaia-X / Simpl跨组织信任、凭证、合同、连接器——Data Space 层不能替代企业内部控制面
竞争焦点校准：2026–2027 窗口争的是元数据模型、数据服务接口、语义/QoD 定义权，而不是押注「独立数据面 vs 增强用户面」的最终输赢。

Ericsson：演进式「智能织物 / 数据网格」

公开叙事强调 AI-native intelligent fabric、AI-ready data mesh、「采集一次、授权多用」；产品拼图含 NWDAF、智能自动化平台、网络 API / Aduna 生态等。MWC 2026 继续把 5G SA/Advanced 与分布式算力作为通向 6G 的路径。

中 其 “fabric” 范围常大于 Data Fabric，不宜术语混用。尚无公开证据证明跨 RAN/RIC/SMO/Core 的统一商用 Data Fabric 已广泛部署。

Huawei：专用数据面研究 + 产品桥

研究侧提出 AI-native 6G 专用数据面（DO/DA/DCP 等）与 DaaS；产品/方案侧可见 AI Core、Agentic 方向、数字地图与 Open Gateway 渠道等「通向 6G 的桥」。

中 厂商输入≠3GPP 共识；传输层提案完整，但目录/语义/血缘/治理在叙事中相对薄弱——这正是编织的补位空间。

格局判断：不在「mesh」与「data plane」之间机械站队；可争控制点在 RAN 语义与 QoD、近源执行、实时分层、北向可治理供给，以及治理权归属运营商的可移植能力。
03 · Trend Outlook

产业趋势预判：数据编织与 6G 结合如何展开

总命题：编织从「数据集成层」走向「可信智能控制面」。集成层不消失，仍负责执行；控制面负责感知、语义、策略与回滚。6G 把这一命题从企业 IT 推到电信实时与多主体约束下。

因果链：四步上移

可观察
元数据事件化 + 流批/开放目录：把管道运行态变成结构、质量、成本、权限的即时信号——6G 侧对应遥测/管理数据的在线标注与血缘。
可理解
语义控制平面 + 数据产品/契约即代码：表名升级为版本化含义、用途与 SLO——6G 侧对应 RAN/管理/感知多本体对齐与 QoD。
可行动
受治理 RAG + Agent 可操作 Fabric：从检索辅助到低风险编排/执行——6G 侧对应 rApp/xApp/运维 Agent，但不得跳过职责分离。
可信
隐私增强/机密计算 + 接入 Data Space：把「能做」收束为「在证明与合同下可做」——支撑感知变现与跨主体协作。

与 6G 结合的展开路径（预判）

高

路径 A · 网络内循环优先

先打通「源 → 特征 → 模型 → 策略 → 动作 → 效果」证据链，服务自智与节能/故障/负载类闭环。这是当期真实付费最近的路径。

中高

路径 B · 北向数据产品化

在内部语义与 QoD 稳定后，向 Core/AF/MEC/行业供给最小必要产品。依赖 Rel-21 前后系统级框架与管理服务成熟度。

中

路径 C · 感知与空间外溢

ISAC 数据产品化与 Data Space 互操作打开新收入想象，但付费需求与旁观者隐私约束仍需验证；宜试点而非押注。

趋势边界：「走向可信智能控制面」≠ 无人值守，≠ 取消集成层。若事件化元数据与契约基线未立，直接上 Agent/自治，只会把隐式错误自动化放大——在 RAN 快环中尤其危险。
04 · 3-Year / 5-Year View

趋势判断总结：3 年看透、5 年看清

重点写清未来 1–3 年可验证事项；5 年给出方向性终局与仍低确定性的边界。时间锚点对齐 Rel-20/21 与编织三阶段。

3 年看透（约 2026–2028）

判断含义信心若看错的代价
标准争的是定义权，不是押路线 WT#5 / 管理侧研究与开放接口条目收敛；目录、语义、QoD、数据服务接口可提交可争论。独立面/增强面裁决不影响「需要编织层」。 高 把资源押在单一网元命名，错过接口与本体窗口
工程底座必达，自治不可宣称 事件化元数据、血缘、契约、开放 Catalog、受治理助手成为基线；价值是把运行态变成可观察信号。 高 平台叙事超前，现场无证据链
RAN 内循环优先于北向大平台 先语义+QoD+少数高价值闭环（如负载/节能/故障类），打通证据链；无 KPI/定位时间收益则停止平台扩张。 高 中央湖+通用 Agent 进快环，事故与抵制
两处口径必须校准 亚毫秒≠编织时延；ZB/天≠存传投资依据。主战场在秒级流上标注与分钟级管理面。 高 错误投资与错误 KPI
厂商统一商用 Fabric 证据仍缺 Ericsson / Huawei 均在拼数据—智能—API 能力，但跨域统一商用 Fabric 未获广泛公开证明；跟进控制面、差异化近源与 QoD。 中高 被叙事牵着走，失去补位空间

5 年看清（约 2029–2031+）

判断含义信心
控制面主体能力成型 ontology 连接数据—模型—政策—动作；「可信」成为上线门槛；低风险建议可规模自动，高风险保持仿真/审批/回滚。 中高
首批 6G 规范落地后，北向供给形态可见 随 Rel-21 实现与早期商用准备（业界多指向 2030 前后），系统级数据框架与跨域暴露方式从研究变为可对接对象；此时才谈规模化北向数据产品。 中
条件性自治，而非无人治理 自动映射、异常调查、管道/边云优化更成熟；跨企业自主签约、通用全同态、完全无人治理仍低确定性——自治级别由证据与风险预算决定。 中
Data Space / 感知变现进入验证窗口 内部 Fabric 对接外部信任机制的工程路径清晰化；感知产品化能否形成稳定付费仍待市场检验。 中低
收束断言：3 年把「可观察的电信数据底座」做成；5 年把「可信的语义—策略控制面」做成。北向生意与感知变现在证据之前都只是期权，不是主叙事。
